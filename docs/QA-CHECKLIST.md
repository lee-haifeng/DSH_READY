# 真机验证清单

这个工程的 ArkTS 代码编译通过、纯逻辑有自动化测试覆盖，但**界面行为必须在真机或模拟器上确认**
（本机没有可用的鸿蒙设备/模拟器镜像）。第一次装机后按这个清单走一遍，能覆盖大部分风险点。

标记：`[ ]` 未验证，`[x]` 通过。

## 一、启动与首屏

- [ ] 冷启动进入聊天页，顶部标题显示「新对话」，中间是空状态和两条建议
- [ ] 顶部菜单栏没有被状态栏遮挡：标题行落在状态栏下方，刘海/挖孔区没有内容
- [ ] 底部输入框没有被手势导航条压住，上滑返回时不会误触发送
- [ ] 旋转屏幕或改字体大小后，上下留白自动跟着变化（不会失效变回重叠）
- [ ] 状态栏文字颜色与主题一致（深色主题下是浅色文字）
- [ ] 底部输入框可以正常获得焦点、弹出键盘，输入框不被键盘遮挡
- [ ] 切换系统深色模式（设置项为「跟随系统」时），界面立即或重启后跟着变色

## 二、API Key 与设置

- [ ] ⚙ → API Key 粘贴密钥 → 保存后显示 `••••xxxx`
- [ ] 未配置密钥时点发送：弹出提示并自动打开设置页
- [ ] 杀掉进程重进，密钥仍然存在（Asset Store 生效）
- [ ] 点「清除密钥」后再发送，同样提示未配置
- [ ] 修改模型 / 推理强度 / 主题 / 语言后立即生效
- [ ] 「关于」里的版本号、上游仓库、协议显示正常

## 三、单轮对话

- [ ] 发送一句话，回复逐字流式出现，不闪烁、不整段跳变
- [ ] 长回复时列表自动跟到底部；手动上滑后不再强制跟随（如果会强制，记下来）
- [ ] 推理过程面板可以展开/收起，内容完整
- [ ] 回复结束后底部出现耗时与 token 数
- [ ] 点 ■ 停止：当前已生成的内容保留在会话里，并标注「已停止」
- [ ] 停止后立刻再发一条，能正常工作

## 四、工具调用

- [ ] 让模型「搜索今天的新闻」：出现「搜索网络」卡片，状态从执行中变为已完成
- [ ] 点卡片能展开，看到参数 JSON 和结果文本
- [ ] 让模型「给我列个三步计划」：出现任务清单卡片
- [ ] 顶部下方出现任务清单条，显示完成进度，可展开
- [ ] 工具失败时（比如断网）卡片显示红色「执行失败」，对话不中断

## 五、多会话与搜索

- [ ] 发几条消息后 ☰ 打开会话列表，能看到刚生成的会话，标题是自动生成的短语
- [ ] 头像是空的会话显示「新对话」
- [ ] 「＋ 新建会话」后回到空状态，再发消息生成第二个会话
- [ ] 搜索框输入关键词，能看到命中会话与片段；清除后恢复完整列表
- [ ] 长按会话行 → 重命名 → 标题更新
- [ ] 长按会话行 → 删除 → 确认后列表里消失
- [ ] 切回旧会话，历史消息完整、顺序正确、图片还在

## 六、目标模式

- [ ] ◎ 打开目标面板，输入目标并开始
- [ ] 回复结束后自动进入下一轮，列表里出现「轮次 N/M」的小灰条
- [ ] 顶部标题下方显示目标进行中
- [ ] 目标面板可以暂停 / 继续 / 标记完成 / 结束
- [ ] 达到轮次上限后自动暂停并提示

## 七、图片

- [ ] ＋ 选一张照片，输入框上方出现缩略图
- [ ] 点缩略图右上角 × 可以移除
- [ ] 带图发送后，气泡里显示图片，模型能描述图片内容
- [ ] 图片超过 8MB 时被拒绝并有提示（可选）

## 八、语音

- [ ] 第一次点麦克风弹出麦克风权限申请，允许后开始聆听
- [ ] 说话时输入框上方显示实时识别文字
- [ ] 说完自动结束，识别结果可用
- [ ] 拒绝权限时提示需要麦克风权限，不崩溃

## 九、长期记忆

- [ ] 告诉它「我在做鸿蒙移植项目」，对话里出现「记住这件事」卡片
- [ ] 设置 → 长期记忆里能看到这条，数量 +1
- [ ] 点 ☆ 置顶变 ★，重进设置页仍然是置顶状态
- [ ] 点 × 删掉单条，确认后列表少一条
- [ ] 「清空全部」二次确认后列表变空
- [ ] 新建会话问「你记得我在做什么项目吗」，它能答出来（说明注入生效）
- [ ] 说「忘掉我的项目」，它先回忆再删除，之后不再提起
- [ ] 设置里「自动提炼长期记忆」默认开启；聊够 4 条以上消息后回到设置，
      条目应该自己变多了（不需要你主动说「记住」）
- [ ] 关掉这个开关后再聊几轮，条目数量不再自动增加
- [ ] 断网状态下连续发消息，不应出现卡顿或崩溃（提炼失败要静默）

## 十、异常与边界

- [ ] 飞行模式下发送：出现网络错误提示，不卡死
- [ ] 密钥填错：提示「API Key 无效」
- [ ] 长对话（几十轮）滚动流畅，输入不卡顿
- [ ] 会话列表有几十个会话时，打开和搜索仍然跟手
- [ ] 旋转屏幕 / 分屏（平板）布局不塌

## 十一、需要重点观察的现象

这些是编译期无法排除、最可能在真机上出问题的地方：

1. **`List` 内的流式重绘**：长回复时是否掉帧。
2. **`Text` 内嵌套 `ForEach` + `Span`**（Markdown 行内渲染）：粗体/行内代码/链接是否都正确显示。
3. **Markdown 表格**：横向滚动是否与外层列表滚动冲突。
4. **`bindSheet` 内三个 sheet 复用**：切换面板时内容是否错乱、关闭动画是否正常。
5. **`ask_user_question` 弹层**：`Blank()` 点击关闭是否与输入框点击冲突。
6. **会话列表长按菜单**与点击的冲突。
